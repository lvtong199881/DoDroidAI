# 设计说明 — 欢迎弹窗主按钮新增右箭头（m94psibp）

> 平台 Android / Flutter ｜ 类型：UI 视觉增强（不改交互）｜ 依据：PRD v1.0、需求卡片 v1.0
> 产物：`design/layouts.json`（结构事实来源）→ `design/svg/*.svg`（设计源）→ `design/boxes.json`（量测）→ `design-images/*.png`（3× 预览）

## 1. 设计结论

在欢迎弹窗唯一主按钮的内部、文字左侧，加一枚 **20×20dp 的 Material 实心 `arrow_forward`**：与文字 **8dp** 间距、**与文字同色（onPrimary）**、**垂直居中**；图标与文字作为一组在按钮内水平居中。按钮全宽、胶囊、最小高 48dp 不变；文案、标题、导语、三条卖点、弹窗宽高、点击与关闭逻辑全部不动。

按钮从「`开始使用`」变为「`→ 开始使用`」，「`Get started`」变为「`→ Get started`」。

## 5. 设计决策与理由

1. **整组居中，而不是让文字保持光学居中**。Material 按钮带前置图标时，图标+文字作为一组居中；Flutter 默认行为也是如此。副作用：文字视觉中点相对按钮中线右移 (20+8)/2 = **14dp**。若改成「文字不动、箭头挤进左侧空白」，需要给图标预留 28dp 内边距，1×/2× 下都会让文字偏右，反而更不稳，故不采用。
2. **图标固定 20dp 不缩放**（A-1、AC-3）。2× 下图标相对 30sp 文字偏小（见 F07），是刻意取舍：若图标跟着放大，320dp + 2× 会把文字挤成 3 行甚至溢出。
3. **2× + 320dp + 英文允许换行**（F08）。按钮内容宽 240−48 = 192dp，图标占 28dp，文字可用 164dp；「Get started」在 30sp 下约 173dp 放不下 → 换行、按钮 48→100dp，图标与文字块垂直居中。比「缩字号」或「压内边距到 16dp 靠 7dp 余量硬撑」更稳（后者换台字体宽一点的机器就会破）。
4. **保留左右 24dp 内边距**。1× 下内容自适应居中，内边距不参与视觉；2× 下给内容留对称余量，也避免文字贴胶囊圆角。
5. **极端字号用「按钮区裁切帧」**（F07/F08）。2× 下整个弹窗约 1100dp 高，超出 800dp 设备画布；裁切帧保持**按钮真实宽度 240dp**，足以验收 AC-3 的「不截断、不重叠、不越界」，且不必拿假高度画布充数。
6. **空态用「弹窗未展示」帧**（F00）。本需求无数据列表，空态即弹窗不存在；同时用作 AC-6「关闭后停留首页」与 AC-10「其余元素不变」的对照组。
7. **不新增按压/禁用/聚焦帧**。A-4 明确无独立按压态；连点由既有 `_closing` 保护，无视觉差异。

## 6. 与现有设计规范的差异 / 本次前提（需开发知悉）

1. **仓库未包含工程源码与 `docs/ui-screenshots`**：本次 checkout 只有需求文档。色板与字号取自本技能金标准 `examples/welcome-dialog`（与 `a7efpfbp` 欢迎弹窗同一套 token），即 `primary #4D6BFE / onPrimary #FFFFFF`、深色 `primary #8FA6FF / onPrimary #0A1F5C`、标题 20sp·w600、正文 15/13sp、按钮 15sp·w600、弹窗圆角 16。**若工程主题实际值不同，只影响 icon 与文字取 `onPrimary` 的结果，替换 token 即可，不改结构。**
2. **字体降级**：出图环境无 Roboto / Noto Sans CJK，用 `Segoe UI` + `Microsoft YaHei` 近似；**真机以系统字体为准**，字形宽度约 ±3~5% 差异，可能影响英文极窄屏的换行点（F06/F08 的换行位置仅供对照，最终以真机截图为准）。
3. **弹窗投影**：渲染器只给根节点套 elevation，弹窗作为子节点未画阴影；真机 `Dialog` 自带 elevation。层级关系由遮罩表达，不影响按钮判断。
4. **背景为纯色占位**：截图库无基线，按新页面整页出稿；首页内容不在本需求范围，未臆造、未重绘。
5. **标注层不是产品 UI**：F00 左上卡片、F07/F08 顶部与底部说明、F09 整帧均为设计标注。F07/F08 里标注用 `annotation2x`（6sp × 帧字号 2 = 12px）呈现，避免标注被 2× 放大挤爆画布。
6. **2× 帧的内边距不放大**：Flutter 默认会按 textScaler 放大按钮内边距；本稿按「内边距固定 上下 14 / 左右 24」出图。若实现沿用默认放大，按钮会更高、英文更早换行，**AC-3 仍满足**，只是高度与换行点与本稿不同。**建议实现侧固定 padding**，与本稿一致。
7. **不新增**任何文案 key、图标字体外的素材、埋点、权限与依赖（A-5）。

## 8. 出稿与自查记录

- **渲染**：`svggen.cjs` 校验通过、10 帧一次出齐；`svg2png.cjs --scale=3` 出 10 张 PNG（Chrome 不可用时按脚本降级 resvg）。SVG 全部由 `layouts.json` 生成，**没有手写 SVG 坐标充当设计源**。
- **越界自查**：用 SVG 绝对坐标 + `boxes.json` 尺寸逐帧比对，10 帧文本无越出画布；弹窗内文字盒右缘 = 内容盒右缘（360 屏 316dp / 320 屏 276dp），未压内边距；F09 最小字号标注未越界。
- **几何**：F01 弹窗 320×419.7 @ y=190.2（垂直居中）、按钮 280×48；F03 弹窗 320×496.5；F05 弹窗 280×438.6 @ y=180.7、按钮 240×48；F06 弹窗 280×592.9；F07 按钮 240×64；F08 按钮 240×100。
- **一致性**：`design/` 下三件（layouts.json / svg / boxes.json）与 `design-images/` 的 PNG 均为最后一次渲染产物，帧名一一对应。
