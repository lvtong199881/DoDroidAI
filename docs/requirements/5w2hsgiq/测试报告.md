## 8. 缺陷与观察

**失败项：0 条。** 以下为观察/未覆盖项，均不判为功能失败。

### 8.1 观察 1：欢迎弹窗展示期间出现系统 ANR（环境相关，待复测）

- **现象**：共观察到 3 次 ANR：
  1. 首次安装后冷启动期间出现「System UI isn't responding」；
  2. 同时段出现「dodroidai isn't responding」；
  3. 01:03 在欢迎弹窗展示期间按 Home，系统判定 `dodroidai` 无响应（`dumpsys activity lastanr`：`Reason: Input dispatching timed out ... Waited 5011ms for FocusEvent(hasFocus=false)`）。
- **证据**：`docs/ui-screenshots/welcome/anr-observation.png`（ANR 弹窗覆盖在欢迎弹窗之上）；`dumpsys activity lastanr` 原文见执行记录。
- **判断**：同机 System UI 也发生 ANR，且本轮线程/宿主明显过载（冷启动约 50s、首帧 hero 约 15s 才绘制、另一应用在后台播放），**优先按环境性能问题处理，不判本需求失败**；但 ANR 属用户可见现象，建议在健康设备/真机上复测首帧与切后台性能，确认非新引入的长时间主线程阻塞。
- **影响**：测试期间需要点「Wait」恢复，未导致崩溃或数据异常；欢迎弹窗最终均正常显示/关闭。

### 8.2 观察 2：应用语言为中文时 `WelcomeLog` 仍上报 `locale=en`（口径待确认）

- **现象**：应用内语言切到「简体中文」后，弹窗文案为中文，但日志为 `welcome_check ... locale=en`、`welcome_shown ... locale=en`；系统语言为 `en-US`。
- **影响**：若按 PRD 第 9 节「可按 entry / locale 分组」统计，中文用户会被归到 en 组，展示量/关闭率分组失真。
- **判断**：PRD 未明确 `locale` 取「应用语言」还是「系统语言」，因此记为**口径待确认**，不判失败。建议确认后统一埋点口径；若应按应用语言，需要开发修正。

### 8.3 观察 3：补测阶段设备离线（环境）

- **现象**：01:29 之后 `adb shell`、`logcat`、`dumpsys` 全部挂起；`adb emu avd name` 报 `could not connect to TCP port 5554: 拒绝连接`；`adb devices` 仍残留 `emulator-5554 device`。
- **影响**：原计划的「标记读写失败」「断网本地资源」两项补测无法执行；不是应用失败。
- **处置**：按约束未重启/重置设备、未改用另一台在线设备；在回执中报环境问题。

### 8.4 观察 4：设备上遗留另一应用（范围外）

- 设备前台曾出现 `com.mohanlv.bilibilix`（Bilibili 客户端）并在后台持续播放，可能是设备分配前的遗留状态；已 `force-stop` 以减少干扰。与本需求无关，仅记录。

### 8.5 观察 5：应用内中英混排（范围外）

- 应用语言为 English 时，欢迎弹窗为英文，但抽屉/设置/底部输入区仍有中文（「笔记」「记忆」「按住说话」等）；属于既有本地化不完整，与本需求无关，仅记录。
