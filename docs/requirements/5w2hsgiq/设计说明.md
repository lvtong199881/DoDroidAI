## 2. 设计结论

结构由「主标题 → 导语 → 三组卖点 → 按钮」改为：

**欢迎图（贴边铺满，2:1）→ 主标题（居中）→ 副标题（居中）→「开始使用」（底部固定）**

- 欢迎图左右贴弹窗边缘（水平留白 0dp），顶部两角随弹窗 16dp 圆角裁切，高度按 2:1 等比缩放，不拉伸、不裁切。
- 三组卖点（图标 + 标题 + 描述）整组删除；导语 `welcomeIntro` 保留为副标题。
- 主标题、副标题在内容区水平居中；标题→副标题间距 8dp。
- 弹窗整体保持：左右 inset 20dp、圆角 16dp、最大高度屏幕 80%、内容区左右内边距 24dp、底部按钮固定。
- 欢迎图出浅色/深色两版（PRD A3 允许单张或两套，设计选两套，保证 AC-14 两种背景下的主体轮廓）。

### 5.4 降级

- **超高（AC-12）**：图片 + 标题 + 副标题一起滚动，初始在顶部；按钮固定在弹窗底部，始终可见可点。不压缩图片、不裁文字、不隐藏按钮。
- **图片失败（AC-13）**：图片区域留空、**不预占高度**（避免空白大块），标题/副标题/按钮照常展示，弹窗可关闭；不显示破图、不显示技术错误文案。
- **深浅切换（AC-14）**：两版素材同构图，切换主题只换图，不改布局与文字色。

## 6. 与现有设计规范的差异

1. **字体降级**：出图环境用 `Segoe UI` / `Microsoft YaHei` 近似，真机为 Roboto / 系统中文（Noto Sans CJK 或厂商字体）。字号、行高、字重按规范固定，PNG 上的断行位置仅供预览；真机断行以系统字体为准。
2. **设计稿基准宽取 360dp**（Android 主流），并按规范另验 320dp；未单出 375dp 帧。横屏用 640×400 等效画布论证 AC-12，不代表具体机型整页。
3. **新增插画色板**（仅用于欢迎图，未进入 UI 控件 token）：
   - 浅色：底 `#EEF2FF`、装饰圆 `#DDE5FF`、点 `#C6D2F7`、手机面 `#FFFFFF`、屏幕 `#F4F7FF`、描边 `#C3CFF0`、主蓝 `#4D6BFE`、浅蓝 `#8FA6FF`；
   - 深色：底 `#1C2436`、装饰圆 `#232D45`、点 `#2C3957`、手机面 `#2A3348`、屏幕 `#212A3E`、描边 `#3D4B6B`、主蓝 `#8FA6FF`、辅蓝 `#6E88FF`。
   - UI 控件颜色仍只取主题 `surface / onSurface / onSurfaceVariant / primary / onPrimary`，插画色不用于文字、按钮、边框。
4. **两套素材而非单张自适应**：PRD A3 允许二者，选两套以保证深色下不出现「浅色大块」的突兀感与不可辨区块（AC-14）。
5. **图片失败取「留空」而非「占位块」**：PRD REQ-7 允许留空或占位；留空不破坏「图片→标题→副标题」的紧凑层级，也不会出现一块无意义灰块。
6. **不加分割线**：图片与正文靠留白分界（规范优先留白），避免弹窗内出现多余线条。
7. **背景占位**：因无 `docs/ui-screenshots/` 真实截图，F02–F05、F07 背景为规范底色（浅色 N1 `#F7F8FA` / 深色 N0 `#0F1115`）+ 54% 遮罩；它只用于呈现「弹窗浮在首页上」的对比关系，**不代表首页真实内容**，首页不在本需求范围内。
8. **320dp 英文副标题为 2 行**（`…phone do` / `it.`）：文案取自 PRD 不可改、字号规范固定，PRD 7.1 已允许英文副标题换行；两行均居中（AC-7）。若开发实测 Roboto 下能排成 1 行，属正常差异，不视为偏离。

## 8. 自查与出图说明

- `boxes.json` 中无内容盒超出画布或父容器：文字块宽度 = 内容宽度（360dp 宽为 272，320dp 宽为 232），行数分别为 1 / 2（F05 英文副标题）；图片宽均等于弹窗宽，高度 = 宽 ÷ 2。
- 每帧为独立 frame，未拼图；帧内容与 `layouts.json` 一致（本轮改动后已重跑渲染）。
- **出图工具说明**：自带 `svg2png.cjs` 依赖 Chrome/Edge 无头模式，本机沙箱禁止命名管道，Chrome 启动即崩（`mojo platform_channel ... 拒绝访问`），无法出 PNG。改用 `node-canvas` 对**同一份 svg** 做栅格化（`scale=3`、透明底，脚本在 `.render/svg2png-nodecanvas.cjs`，非交付物），SVG 仍是唯一设计源，坐标未手写。
- 本轮只在需求目录写设计产物，**未改项目下任何源码、配置、资源**。
