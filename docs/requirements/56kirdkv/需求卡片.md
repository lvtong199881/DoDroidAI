# 需求卡片：欢迎弹窗新增「AI 配置」说明行

> 依据：《待提问清单.md》Q1–Q7 的用户选择（均选 A）。详细规则见 `PRD.md`。

## 0. 基本信息

| 项 | 内容 |
| --- | --- |
| 需求名称 | 欢迎弹窗新增「AI 配置」说明行 |
| 平台 | Android（Flutter） |
| 影响模块 | 欢迎弹窗（`lib/widgets/welcome_dialog.dart`）、中英文案（`lib/l10n/app_strings.dart`）、欢迎弹窗相关测试；主题 token 只读复用，不修改 `lib/theme/app_theme.dart` |
| 需求来源 | 用户直接提出 |
| 定稿状态 | 已定稿（7 个疑点全部由用户拍板） |

## 1. 目标

- 在欢迎弹窗主标题与现有副标题之间新增一行说明文字「随时可以在设置里改 AI 配置」；只要欢迎弹窗展示就显示，不区分是否已配置 AI。
- 说明行使用 `onSurfaceVariant` 次要色、默认字号 13sp，跟随系统字体缩放；水平居中，窄屏/大字号下自然换行，不截断、不横向溢出。
- 说明行是纯文本，不可点击；不新增页面、路由、权限、埋点或存储。
- 关闭弹窗时，说明行与主标题在现有路由过渡中同步淡出；不新增独立动画，不改变关闭时长。
- 中英文案正确；现有标题、副标题、欢迎图、按钮、关闭方式、一次性门控与日志不回归。

## 2. 范围

- 在欢迎弹窗标题文案区新增说明行：位置、显示条件、中英文案、字号/颜色/对齐/换行、滚动归属、关闭淡出。
- 说明行在已配置/未配置 AI 两种状态下都显示。
- 现有副标题保留，位于说明行下方。
- 更新欢迎弹窗相关测试与断言，覆盖新增文本、样式、位置、换行与淡出。
- 保持现有欢迎图、标题、副标题、底部按钮、关闭方式、一次性门控、`welcome_*` 日志与本地存储不变。

## 3. 明确不做的事

- 不把说明行做成可点击链接、跳转「设置 → AI 配置」或任何新入口；配置入口仍是现有「去配置AI」按钮或侧边栏 → 设置 → AI 配置。
- 不按 AI 配置状态隐藏、替换或改写说明行；两种状态显示同一文案。
- 不新增页面、路由、弹窗、加载态、空态或错误态。
- 不修改现有标题、副标题、欢迎图、底部按钮的文案、字号、颜色与行为。
- 不修改关闭方式、一次性展示门控、`welcome_shown` / `welcome_dismissed` / `welcome_error` 的字段与含义。
- 不新增埋点、release 上报、数据库表、文件或 SharedPreferences 键。
- 不新增运行时权限，因此没有新增权限文案。
- 不做全应用无障碍改造；不做专项 TalkBack 全流程验收，仅保证说明行是普通文本、没有按钮语义。
- 不做折叠屏展开/折叠、分屏、悬浮窗的专项布局；沿用现有弹窗的宽度、最大高度与滚动行为。
- 不修改 AI 配置读取、完整性判断、校验或网络请求逻辑。
- 不改变关闭动画的时长与曲线，不新增独立淡出段；不为了说明行给老用户补弹欢迎弹窗。

## 5. 验收标准

**术语口径**：

- 弹窗矩形 = 欢迎弹窗可见 Material 卡片的外接矩形，不含遮罩。
- 标题文案区 = 欢迎弹窗内包含主标题、说明行、副标题的可滚动纵向区域。
- 关闭路径 = 现有四个出口：底部「开始使用」、底部「去配置AI」、右上角关闭按钮、系统返回键。
- 13sp = 默认系统字号（缩放 1.0）下的基准字号；系统缩放 2 倍时按 26sp 渲染，不是固定 13 逻辑像素。
- 次要色 = `colorScheme.onSurfaceVariant`：浅色 `#5B6270` / 深色 `#A6ADBB`。

## 7. 依赖与风险

- 依赖设计阶段给出说明行的上下间距；PRD 只约束位置、13sp 基准字号、`onSurfaceVariant`、居中、换行与淡出，不写死间距。
- 按用户选择，说明行紧贴主标题，字号顺序为 20/13/15；副标题比说明行大，若间距处理不当会显得层级跳跃。设计需用间距和对齐弱化，但不得改动副标题字号或顺序。
- 320dp 窄屏、2 倍字号下说明行会换行到多行；必须保持现有「内容区滚动、按钮区固定」的结构，底部按钮不能被长文案挤走（AC-11、AC-12）。
- 未配置用户会同时看到说明行和「去配置AI」按钮；说明行只陈述「以后可改」，不替代按钮，文案不得让用户误以为必须先配置。
- 关闭淡出依赖现有 `showDialog` 路由过渡；若后续 Flutter/设计改动关闭动画，AC-14、AC-15 需重新核对。
- 现有测试若对标题/副标题位置、弹窗高度做精确断言，新增一行会导致失败；应更新为包含说明行的新布局，不得放宽既有行为断言。
- 无新增后端、权限、存储字段或数据迁移；说明行不可点击是用户 Q2 的明确选择，不作为缺陷。
