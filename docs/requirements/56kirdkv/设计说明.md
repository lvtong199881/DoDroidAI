## 0. 结论

在主标题与现有副标题之间新增 13sp、`onSurfaceVariant`、水平居中的说明行「随时可以在设置里改 AI 配置」。说明行紧贴主标题（上间距 6dp），与副标题拉开到 12dp；主标题 20 / 说明行 13 / 副标题 15 的顺序按用户 Q1 的决定执行，不调整副标题字号。说明行属于标题文案区、随标题一起滚动，关闭时沿用现有整体淡出，不新增动画、不可点击、不新增入口。

## 1. 设计依据与边界

**依据**：`PRD.md` v1.0、《需求卡片.md》、项目现有主题 token（`onSurface` / `onSurfaceVariant` / `primary` / `surface`）、skill 金标准 `examples/welcome-dialog` 的弹窗结构与尺寸基线。

**本次只做视觉设计**：

- 不写实现代码、不定义接口、不改 PRD。
- 不改变现有欢迎图、标题、副标题、底部按钮的文案与字号。
- 不新增页面、路由、入口、加载态、错误态、埋点或权限。
- 不设计新的关闭动画；关闭淡出沿用现有 `showDialog` 路由过渡。

**关于「整页」**：项目截图库里没有欢迎弹窗本身的真实截图，按新页面处理，每帧都是完整整页画布（含首页背景、遮罩、弹窗）。弹窗为本次设计对象；遮罩下的首页只作上下文，不据此验收，也不改动首页。

## 3. 设计规格

### 3.1 弹窗与页面基线

| 项 | 360dp 屏 | 320dp 屏 | 来源 / 说明 |
| --- | --- | --- | --- |
| 画布 | 360×800 | 320×640 | PRD 测试设备覆盖 360×800、320×640 |
| 弹窗宽度 | 320 | 280 | 金标准基线：左右各 20dp 边距；窄屏沿用同一 20dp 边距 |
| 弹窗水平位置 | x=20 | x=20 | 居中 |
| 弹窗顶部位置 | y=24 | y=24 | 沿用金标准欢迎弹窗的顶部定位；在状态栏下方 |
| 弹窗圆角 | 16 | 16 | 项目 dialog 圆角 |
| 遮罩 | `rgba(0,0,0,0.54)` | 同左 | 现有 scrim token |
| 阴影 | `0 8px 24px rgba(0,0,0,0.18)`（深色 0.55） | 同左 | 现有 dialog 阴影 |

> 320dp 下的 280dp 弹窗宽度是按「左右各 20dp」推导的；若现有实现另有固定最大宽度或内边距，以现有实现为准，说明行规格不受影响。

### 3.2 字号、颜色、行高

| 层级 | 字号 | 字重 | 行高 | 颜色 token | 浅色值 | 深色值 |
| --- | --- | --- | --- | --- | --- | --- |
| 主标题 | 20sp | 600 | 1.3（26dp） | `onSurface` | `#171A1F` | `#E6E8EC` |
| **说明行（新增）** | **13sp** | **400** | **1.4（18.2dp）** | **`onSurfaceVariant`** | **`#5B6270`** | **`#A6ADBB`** |
| 副标题 | 15sp | 400 | 1.4（21dp） | `onSurfaceVariant` | `#5B6270` | `#A6ADBB` |
| 主按钮 | 15sp | 600 | 1.2 | `onPrimary` | `#FFFFFF` | `#0A1F5C` |
| 次按钮 | 15sp | 500 | 1.2 | `primary` | `#4D6BFE` | `#8FA6FF` |

说明行与副标题同为 `onSurfaceVariant`；说明行靠 13sp 字号和更小的上下间距与副标题区分，不加背景、边框、下划线、图标或链接色。

**说明行对比度（按 WCAG 公式计算）**：

| 组合 | 对比度 | 结论 |
| --- | --- | --- |
| `#5B6270` on `#FFFFFF`（浅色弹窗） | 6.13:1 | ≥ 4.5，达标 |
| `#A6ADBB` on `#161920`（深色弹窗） | 7.80:1 | ≥ 4.5，达标 |

### 3.3 间距

| 位置 | 间距 | 说明 |
| --- | --- | --- |
| 欢迎图下沿 → 主标题 | 20dp | 标题文案区上内边距 |
| 主标题 → 说明行 | **6dp** | 让说明行读作主标题的补充，落实「紧贴主标题」 |
| 说明行 → 副标题 | **12dp** | 把说明行与副标题分成两段，弱化 13→15 的字号回跳 |
| 副标题 → 首个按钮 | 20dp | 标题文案区下内边距 8 + 底部区上内边距 12 |
| 次按钮 → 主按钮 | **10dp** | 两个 48dp 胶囊按钮之间 |
| 主按钮 → 弹窗底 | 20dp | 底部区内边距 |
| 说明行与关闭按钮 | 图片存在时远距；图片缺失时 ≥ 14dp | 图片缺失时标题区从 68dp 起，关闭按钮外接矩形底 54dp |

标题文案区内边距为 `[上 20, 右 24, 下 8, 左 24]`，底部区为 `[上 12, 右 20, 下 20, 左 20]`；这两个值与金标准一致。新增加的间距只有 **6 / 12 / 10** 三个值。

### 3.4 说明行专项规格

| 项 | 规格 |
| --- | --- |
| 位置 | 主标题之后、现有副标题之前；固定顺序，不随语言、字号、配置状态变化 |
| 字号 | 13sp 基准；跟随系统字体缩放，2 倍时 26sp；不设最大缩放上限 |
| 字重 / 行高 | 400 / 1.4 |
| 颜色 | `onSurfaceVariant`：浅色 `#5B6270`，深色 `#A6ADBB` |
| 对齐 | 水平居中，文本块宽度 = 标题文案区宽度（360 屏 272dp，320 屏 232dp）；与主标题共用同一条水平中心线 |
| 换行 | 自然换行，不省略、不截断、不设最大行数；无横向滚动、无横向溢出 |
| 文字块 | 无背景、无边框、无阴影、无图标、无下划线、无链接色 |
| 滚动归属 | 属于标题文案区，随主标题同步滚动；不固定在弹窗顶部或底部 |
| 内容 | 纯文本；无占位符、动态值、用户名或配置内容 |
| 字面量 | 中文「随时可以在设置里改 AI 配置」；英文「You can change your AI config anytime in Settings.」 |

**各帧实测行数**（来自 `boxes.json`）：

- 中文 360 / 320：1 行（文本估宽约 165dp / 内容宽 272dp、232dp）。
- 英文 360：2 行（文本估宽约 322dp > 272dp）。
- 英文 320：2 行。
- 2 倍字号中文 360：2 行（26sp 下文本估宽约 329dp > 272dp）。

### 3.5 关闭按钮与欢迎图缺失

| 项 | 规格 |
| --- | --- |
| 命中区 | 48×48dp |
| 视觉圆底 | 32dp 圆，`rgba(255,255,255,0.94)` 填充，`rgba(23,26,31,0.10)` 1dp 描边 |
| 图标 | 16dp 关闭叉，`#171A1F`；线宽按 24 视口 2.0 缩放 |
| 位置 | 欢迎图存在时叠在图片右上角，距弹窗上/右各约 12dp；图片缺失时放在顶部 64dp 关闭条内，同样距上/右约 12dp |
| 图片缺失 | 图片区整块折叠，标题文案区从顶部 64dp 条下方开始（标题 y≈68dp），说明行 y≈100dp，关闭按钮外接矩形底≈54dp，二者间距 14dp |
| 行为 | 沿用现有右上角关闭行为；本稿只补视觉样式，不改关闭逻辑与命中后的行为 |

> 若现有实现已有自己的关闭按钮样式，可沿用现有样式；本稿的 32/48 尺寸与圆形底是为了在没有截图对照时保证两种底图上的对比度，不构成对关闭方式的修改。

### 3.6 底部按钮

- **未配置 AI**：次按钮「去配置AI」在上，主按钮「开始使用」在下；两个按钮都是全宽 48dp 胶囊，间距 10dp。
  - 次按钮：描边胶囊，透明底，`primary` 1.5dp 描边，`primary` 文字，15sp/500。
  - 主按钮：`primary` 填充，`onPrimary` 文字，15sp/600。
- **已配置 AI**：只保留主按钮「开始使用」，底部区高度 80dp（未配置时为 138dp）。
- 底部区固定，不参与标题文案区滚动；2 倍字号下按钮文字 30sp，48dp 高度仍可容纳，按钮完整可见。

### 3.7 欢迎图

- 沿用现有 2:1 贴边欢迎图：360 屏 320×160，320 屏 280×140；上、左、右贴弹窗边，圆角 16，与弹窗同圆角。
- 本需求**不改欢迎图**；由于现有欢迎图资源不在本次设计输入中，稿件里用同色系「语音波形」矢量占位图表达 2:1 画幅与遮罩关系。开发合入时替换为现有欢迎图资源，尺寸/圆角不变。
- 占位图源文件在 `design/hero/`（`hero-320.png`、`hero-280.png` 及对应 SVG/layouts），主稿通过 image 节点引用；图片四角已烘焙为 16dp 圆角透明，叠加在弹窗白色底上不会出现方角。

## 6. 与现有设计规范的差异

1. **说明行 13sp 小于副标题 15sp**：这是用户 Q1 明确确认的顺序（20 / 13 / 15），不按常规「副标题小于说明行」修正。设计上用 6dp 紧贴上、12dp 拉开下，让说明行读作主标题的补充注记，而不是与副标题竞争。
2. **新增间距 6 / 12 / 10dp**：现有 token 没有这三个值，属于本次版式新增；其余内边距、圆角、按钮高度、阴影、遮罩均沿用现有基线。
3. **字体降级（出图环境）**：真机 Android 使用系统字体（Roboto / Noto Sans CJK）；出图环境 Windows 用 `Segoe UI` + `Microsoft YaHei` 近似。`Microsoft YaHei` 没有 600 字重时，PNG 预览里的中文标题会回退为常规字重，英文标题仍是 600；**不要用 PNG 的中文字重判断真机效果**，开发按主标题 600 实现。说明行 400、副标题 400 不受影响。
4. **320dp 弹窗宽度 280dp**：按「左右各 20dp」推导；若现有实现的最大宽度/边距不同，以现有实现为准。
5. **关闭按钮视觉**：没有既有弹窗截图可对照，本稿补了 32dp 白色圆底 + 16dp 叉、48dp 命中区，保证在深色欢迎图和纯白背景上都有对比。若现有实现已有样式，沿用现有样式即可，不改关闭行为。
6. **欢迎图为占位**：本需求不改欢迎图；稿件中的波形图是 2:1 画幅占位，不是新增素材要求。开发仍用现有欢迎图。
7. **底图来源**：项目截图库没有该页面截图；帧中的首页底图来自设计规范金标准示例里的同应用真实首页截图（`design/assets/reference/`，含 360×800、360×640、320×640 三个尺寸），只作遮罩层级上下文。首页不在本需求范围，不据此验收；遮罩下能看到的「发送消息开始对话」属于背景，不是弹窗内容。
8. **既有主按钮对比度观察（不在本需求整改）**：现有主色 `#4D6BFE` 上的白字对比度约 4.33:1，低于普通字号 4.5:1 的 AA 线；这是既有主题与既有按钮样式，PRD 明确不修改现有按钮配色，本需求不处理。说明行自身的 6.13:1 / 7.80:1 已达标。

## 7. 交互、动效与无障碍

- **不可点击**：说明行是普通文本，没有点击、长按、双击命中区；不新增按钮语义、链接语义或手势。视觉上无背景、无边框、无下划线、无链接色。
- **读屏顺序**：按布局顺序「主标题 → 说明行 → 副标题 → 次按钮 → 主按钮」；说明行不合并进标题，也不单独声明为按钮。
- **关闭淡出**：四个现有出口（开始使用 / 去配置AI / 右上角关闭 / 系统返回键）都走同一条路由过渡；说明行与主标题在同一帧内透明度相同，关闭总时长/曲线不变。不新增 AnimationController、自定义路由或延迟。
- **滚动**：标题文案区可滚动；说明行随主标题同步移动，相对间距不变；底部按钮固定，不被长文案挤走。
- **字号缩放**：说明行跟随系统字体缩放，13sp × 2 = 26sp；不设最大缩放上限、不设最大行数；2 倍字号下允许 2 行以上，由标题文案区滚动承载。
- **语言**：中英文逐字对应 PRD；语言切换后弹窗重建时生效，不要求重启；非中英回退中文。
