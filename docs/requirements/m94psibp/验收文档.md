## 5. 设计与实现偏差

### 5.1 设计稿弹窗结构与真机不一致（文档偏差，非实现偏差）

- **设计稿**（F00–F09）：弹窗无配图占位、含"三条卖点"、只有 1 个主按钮、无关闭 X、无次要按钮。
- **真机**：含顶部插画、无三条卖点、右上关闭 X、次要按钮「去配置 AI / Set up AI」+ 主按钮「开始使用 / Get started」。
- **原因**：设计说明 §6.1 已声明本次出稿环境没有工程源码，按技能金标准示例出稿；实现按 PRD「只加箭头、不改弹窗其他内容」停留在真机现状。
- **判定**：箭头规格（约 20dp、8dp 间距、`onPrimary` 同色、垂直居中、纯装饰、不缩放）与设计一致，REQ-1 已达成；结构差异属设计文档与真实界面的基线偏差，**不判实现失败**。
- **影响**：AC-10 中"三条卖点"在真机不存在，该项按"除主按钮外零差异"判定通过。

### 5.2 主按钮文字水平右移 13.6dp（设计预期内，非偏差）

箭头+文字整组居中导致文字相对按钮中线右移 (20+8)/2=14dp；实测 en 文字中心右移 37.5px=13.6dp，与设计说明 §5.1 的取舍一致，视觉与设计稿一致。

### 5.3 2x + 320dp 下按钮未换行、高度仍 48dp（与设计 F08 的 100dp 预期不同）

真机字体度量下「Get started」30sp 在内容宽 192dp 内仍单行放下，按钮高 48dp、内容不截断，AC-3 判定通过；设计 F08 的换行高度只是示意，不构成偏差。

## 6. 平台能力 / 全局问题（口径待确认，不计入本需求失败）

1. **320dp + 2x 字体时主界面底栏溢出**：`深度思考 / 智能搜索 / + / 键盘` 一行出现 Flutter 黄黑条 `OVERFLOWED BY 42 PIXELS`（右缘可见，`+`/键盘图标被裁切），中/英、浅/深均复现（`acc-11`、`acc-12`、`acc-19`、`acc-20`）。溢出提示位于**弹窗下方的主界面输入栏**，不在欢迎弹窗/主按钮内；属应用既有全局适配问题，PRD 未要求本次处理，且与新增箭头无因果关系。→ 建议单独立项，不阻断本需求。
2. **观察**：应用语言切为中文后，`[welcome] welcome_check/welcome_shown` 的 `locale=en` 仍为 en（疑似取系统 locale 而非应用语言）。PRD 仅冻结 `method` 与 `visible_ms`，AC-12 不受影响；是否修正该字段口径待确认。
