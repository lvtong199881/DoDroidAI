## 2. 目标

- 在欢迎弹窗顶部增加一张欢迎图，作为首屏主视觉；图片左右贴弹窗边缘、宽度撑满、高度按原始宽高比自适应、顶部两角随弹窗 16dp 圆角裁切。
- 删除中间三组卖点（图标 + 标题 + 描述），减少文字。
- 主标题、副标题横向居中；副标题沿用现有导语。
- 不改变一次性展示逻辑：新安装 / 清除数据后首次进入首页看到新版；已看过旧版的老用户升级后不重弹。

## 5. 验收标准

### AC-1（覆盖 REQ-1）

**验收标准**：当欢迎弹窗打开时，欢迎图应当位于弹窗内容最上方，并在主标题之上。

**验证方式**：真机 / 模拟器截图，检查图片顶端与弹窗内容顶端重合，图片位置在主标题上方；可用 widget 树的纵向顺序辅助确认。

### AC-2（覆盖 REQ-1）

**验收标准**：当欢迎弹窗打开时，欢迎图渲染区域的左右边缘应当与弹窗左右边缘重合，水平留白为 0dp（测量误差 ≤1dp）。

**验证方式**：在图片高度中点位置，截图后测量图片左右边缘到弹窗左右边缘的距离；在至少两种屏幕宽度下重复检查。

### AC-3（覆盖 REQ-1）

**验收标准**：当欢迎弹窗打开时，欢迎图顶部两角应当被弹窗的 16dp 圆角裁切，图片像素不应超出弹窗边界。

**验证方式**：截图放大检查顶部两角，确认没有直角、没有图片像素越出弹窗圆角范围。

### AC-4（覆盖 REQ-1）

**验收标准**：当屏幕宽度变化时，欢迎图高度应当按原始宽高比等比缩放，显示宽高比与源图宽高比的偏差不应超过 1%，图片内容不应被拉伸或裁切（圆角裁切除外）。

**验证方式**：在 360dp、411dp 等两种以上宽度截图，比较显示宽高比与设计源图宽高比；检查图片主体无拉伸变形、无内容裁切。

### AC-5（覆盖 REQ-2）

**验收标准**：当欢迎弹窗打开时，原三组卖点的图标、标题和描述均不应出现；中文界面不应出现「按住说话就行」「它会动手，不只是聊天」「会话和笔记留在本机」，英文界面不应出现 `Just hold to talk`、`It acts, not just chats`、`Chats and notes stay on this phone`。

**验证方式**：分别切换中文、英文界面截图；在欢迎弹窗范围内检查上述标题、对应描述文字以及麦克风 / 手机 / 锁图标均不存在。

### AC-6（覆盖 REQ-3）

**验收标准**：当欢迎弹窗打开时，主标题文本块的水平中心应当与弹窗内容区水平中心重合，偏差不应超过 1dp；多行时每一行文本均应当居中。

**验证方式**：截图测量主标题文本块中心与内容区中心；或用 widget test 读取标题与内容区的几何中心对比；中英文各测一次。

### AC-7（覆盖 REQ-4）

**验收标准**：当欢迎弹窗打开时，副标题文本块的水平中心应当与弹窗内容区水平中心重合，偏差不应超过 1dp；多行时每一行文本均应当居中。

**验证方式**：截图测量副标题文本块中心与内容区中心；或用 widget test 读取副标题与内容区的几何中心对比；中英文各测一次。

### AC-8（覆盖 REQ-4、REQ-9）

**验收标准**：当应用语言为中文时，副标题应当显示「说一句话，让手机替你做事。」；当应用语言为英文时，副标题应当显示 `Say it, and let your phone do it.`。

**验证方式**：应用内切换中文 / 英文，截图核对副标题全文；确认没有缺字、错字、截断或省略号。

### AC-9（覆盖 REQ-5）

**验收标准**：当欢迎标记不存在时，首次进入首页应当展示新版欢迎弹窗；展示时欢迎标记文件 `welcome/welcome_dialog_shown_v1` 的内容应当为 `1`。

**验证方式**：新安装或删除欢迎标记后冷启动进入首页；确认弹窗出现，并在弹窗展示时读取标记文件内容为 `1`。

### AC-10（覆盖 REQ-5）

**验收标准**：当旧版本已写入欢迎标记 `1` 的用户覆盖安装新版本后首次启动时，应当不展示新版欢迎弹窗，且标记内容仍为 `1`（不迁移、不重置）。

**验证方式**：先展示并关闭一次旧版弹窗，确认标记为 `1`；用 `adb -s <deviceId> install -r -d <new.apk>` 覆盖安装新包，不清除应用数据；冷启动进入首页，确认无欢迎弹窗，标记仍为 `1`。

### AC-11（覆盖 REQ-5）

**验收标准**：当用户点击「开始使用」或按系统返回键时，欢迎弹窗应当关闭；关闭后本次启动内不应再次展示，连续点击「开始使用」不应弹出多个弹窗或触发多次关闭。

**验证方式**：分别用按钮和系统返回键关闭弹窗；关闭后停留在首页，确认没有第二次弹出；对「开始使用」做快速连续点击，确认只关闭一次、不出现叠加弹窗或异常。

### AC-12（覆盖 REQ-6）

**验收标准**：当弹窗可用高度不足以完整显示欢迎图、主标题和副标题时，图片与文字区域应当可以纵向滚动，底部「开始使用」按钮应当保持可见且可点击，滚动区域内文字不应被裁切。

**验证方式**：用横屏或缩小窗口使内容超过弹窗最大高度；确认图片与文字区域可纵向滚动、滚动到底能看到完整副标题、底部按钮始终可见可点、文字无裁切或溢出。

### AC-13（覆盖 REQ-7）

**验收标准**：当欢迎图使用本地图片资源且资源缺失或解码失败时，弹窗应当继续展示主标题、副标题和「开始使用」按钮，按钮应当可以关闭弹窗，且不应出现无法关闭的空白弹窗或未捕获异常红屏。

**验证方式**：在测试构建中使用不存在的图片资源路径，或临时替换 / 移除资源（仅测试环境）；打开欢迎弹窗，确认标题、副标题、按钮正常展示且可关闭，无红屏、无卡死、无无法关闭的空白弹窗。

### AC-14（覆盖 REQ-8）

**验收标准**：当系统为浅色主题时，欢迎图在 `#FFFFFF` 弹窗背景上应当清晰可辨；当系统为深色主题时，在 `#161920` 背景上应当清晰可辨；图片主体轮廓应当完整，不应出现与当前背景同色而导致不可见的区块。

**验证方式**：分别切换系统浅色、深色主题并截图；检查欢迎图主体轮廓、关键元素完整，图片中不存在与弹窗背景相同且因此看不见的区块；标题、副标题仍清晰可读。

### AC-15（覆盖 REQ-3、REQ-4、REQ-9）

**验收标准**：当应用语言为中文时，主标题应当显示「欢迎使用 DoDroidAI」、按钮应当显示「开始使用」；当应用语言为英文时，主标题应当显示 `Welcome to DoDroidAI`、按钮应当显示 `Get started`；两种语言下主标题、副标题、按钮均不应出现文字截断、重叠或超出弹窗边界。

**验证方式**：切换中文 / 英文界面截图；逐项核对主标题、按钮文案；检查三处文字无截断、无相互重叠、无超出弹窗左右边界。

### AC-16（覆盖 REQ-1、REQ-9）

**验收标准**：当检查欢迎图资源时，图片内不应包含需要随语言切换的中文或英文文案（品牌名 `DoDroidAI` 除外）；中英文界面应使用同一张欢迎图。

**验证方式**：检查图片源文件 / 渲染结果中是否含 slogan、中文标题等需要翻译的文字；切换中英文后对比欢迎图资源与画面，确认未切换为另一张本地化图片。

### AC-17（覆盖 REQ-5）

**验收标准**：当欢迎弹窗展示过程中应用切到后台再回到前台时，弹窗应当仍在展示且不重复叠加；当应用进程在弹窗展示期间被杀、重新启动进入首页时，应当不再展示欢迎弹窗（欢迎标记已在展示前写入）。

**验证方式**：展示弹窗后按 Home 切后台再返回，确认弹窗仍在且只有一个；展示弹窗后用 `adb -s <deviceId> shell am force-stop com.mohanlv.dodroidai` 结束进程，重新启动进入首页，确认不再展示弹窗且标记为 `1`。

## 6. 测试账号与数据

- **测试账号**：无。应用无需登录，欢迎弹窗不依赖账号；本卡片不记录任何凭据。
- **测试数据来源**：测试人员在测试设备 / 模拟器上本地准备，无需外部提供账号或数据。
- **新用户初始状态**：安装 debug 包，或删除欢迎标记；确认 `files/welcome/welcome_dialog_shown_v1` 不存在。
  - debug 包可执行：`adb -s <deviceId> shell run-as com.mohanlv.dodroidai rm -f files/welcome/welcome_dialog_shown_v1`
  - 也可卸载重装，效果等价于首次安装。
- **老用户初始状态**：先完整展示并关闭一次旧版 / 当前版本欢迎弹窗，确认标记内容为 `1`；随后用 `adb -s <deviceId> install -r -d <new.apk>` 覆盖安装新包，不清除应用数据，用于验证 AC-10。
- **语言**：应用内切换中文、英文各验证一次。
- **主题**：系统切换浅色、深色各验证一次（AC-14）。
- **屏幕**：至少一台可调整分辨率 / 窗口的模拟器，或用两台不同宽度（如 360dp、411dp）的设备；另用横屏或缩小窗口验证 AC-12。
- **图片失败**：仅在测试构建或 widget test 中使用不存在的图片资源 / 临时替换资源，不修改正式素材。
- **设备**：`adb devices` 可见的 `emulator-5554` 或真机；多设备时所有 adb 命令带 `-s <deviceId>`。
