## 1. 结论摘要

- **用户已明确决定：本轮打回**，理由为「保存 AI 配置抛 `UnmodifiableListMixin.add` 未捕获异常（AC-9 失败），按测试报告建议退回修复后复测」。
- 验收方独立实测**复现了同一失败**：在「去配置AI」打开的新建配置编辑页保留预设、填入占位 API Key 后点保存，页面无任何反馈、配置未保存、未返回首页；logcat 输出 `Unsupported operation: Cannot add to an unmodifiable list`（`AiConfigStore.saveActive` ← `_ApiConfigScreenState._save`）。
- 该缺陷使「保存并激活配置」这一整条主流程不可用，并直接导致 AC-5 及依赖已配置状态的 AC 无法构造，故**同意打回**。
- 统计：**验收标准 19 条，通过 12，失败 1，未验证 6**。

## 4. AC-9 失败详情（阻断项）

1. 清数据冷启动 → 欢迎弹窗 → 点「去配置AI」→ 进入「新建配置」页（DeepSeek 预设，Base URL / 主模型已填，Key 空）。
2. 点 API 密钥输入框，输入占位值 `sk-placeholder-not-real`。
3. 点「保存」。
4. 现象：页面停留在编辑页；无 toast / 对话框 / 成功提示；按钮可再次点击但同样无结果；配置未落库。
5. logcat（`adb logcat -s flutter:V`，原样摘录）：

```
E flutter : [ERROR:flutter/runtime/dart_vm_initializer.cc(40)] Unhandled Exception: Unsupported operation: Cannot add to an unmodifiable list
E flutter : #0      UnmodifiableListMixin.add (dart:_internal/list.dart:112:5)
E flutter : #1      AiConfigStore.saveActive (package:dodroidai/ai/ai_config.dart:286:15)
E flutter : <asynchronous suspension>
E flutter : #2      _ApiConfigScreenState._save (package:dodroidai/screens/settings/api_config_screen.dart:216:5)
E flutter : <asynchronous suspension>
```

6. 影响：AC-9 直接失败；用户在本需求主路径上无法完成「保存并激活」，且因无法得到「已配置」状态，AC-5 及 AC-2/3/4 的手工构造均被阻断。该异常在 debug 下未被捕获，属于未处理异常（未导致进程退出，但流程中断）。

## 7. 偏差与未验证项（显式列出）

**失败（需修复后复测）**

1. **AC-9（P1）**：保存新建 AI 配置抛未捕获异常 `UnmodifiableListMixin.add`，配置无法保存、无法回到首页，主流程中断。
2. 失败后的次生现象：保存按钮无任何失败反馈，用户不知道发生了什么（属 AC-9 的表现，一并修复/复测）。

**未验证（需说明验证方式或下轮补测）**

3. AC-2 / AC-3 / AC-4：需注入「Base URL / API Key / 主模型为空」的激活配置，UI 无法保存空值，本阶段无法手工构造。
4. AC-5：需已配置完整状态，被 AC-9 阻断；修复后应可在 UI 内构造（保存完整配置 → 重置标记 → 冷启动）。
5. AC-6：需损坏配置 JSON / 注入抛异常读取，本阶段未构造。
6. AC-18：需人为让「打开配置页」失败（debug 异常注入），验收阶段无法经 UI 构造。

**非缺陷观察**

7. 横屏下欢迎弹窗标题/副标题初始在滚动视口外，需滚动查看；与设计 F07 的「内容区滚动、按钮区固定」一致。
8. 英文用户进入的 AI 配置页为中文；PRD 明确不在本需求范围。
