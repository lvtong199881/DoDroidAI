## 7. 偏差、未验证项与说明

### 7.1 AC-10「旧版本升级」的等效口径

本机没有旧版本 APK 可用（构建产物只有当前版本）。验证方法为：用当前包展示并写入标记 `1`，再执行 `install -r -d` 覆盖安装（不清数据）后启动。结果为不重弹、标记仍 `1`，证明「覆盖安装不重置数据 + 标记 `1` 继续生效」的门控行为。局限：未能证明「由旧版本写入的标记」与新版本读取路径完全一致；但标记路径 `files/welcome/welcome_dialog_shown_v1` 与内容 `1` 均沿用现状，风险低。是否要求旧版 APK 严格复验，见 9.1。

### 7.2 AC-13「图片资源失败降级」未验证

AC-13 要求「使用不存在的图片资源路径，或临时替换/移除资源（仅测试环境）」。验收阶段不构建、不改包，无法在现装 debug 包上构造资源缺失；本阶段明确记为**未验证**，不按通过处理。该项需由测试阶段的专项构建（或开发提供的测试 key）提供结论，见 9.2。

### 7.3 中文副标题居中测量口径

见 4.3。字面墨迹 4.55dp 的偏移由末字符全角句号的字身留白造成；按字身框计算居中，判定通过。若需求方坚持「字面墨迹 ≤1dp」口径，需要改文案或加字距，属于需求变更，见 9.3。

### 7.4 观察项（不影响本次 AC）

- **日志 locale 字段**：应用内切换为中文时，启动日志仍为 `welcome_check ... locale=en`（系统 locale），与界面语言不一致。属既有 `WelcomeLog` 字段口径问题，本次未改埋点；若监测指标需要按应用语言分组，需另立需求确认。
- **冷启动耗时**：debug 包冷启动 20–28 秒，为构建形态导致，未观察到 ANR；不影响 AC。
- **英文 320dp 副标题行数**：设计稿按 2 行出图，真机 Roboto 为 1 行；设计说明已允许，文案完整、居中，不算偏差。
- **深色素材与弹窗背景接近**：视觉上主体可辨，若后续希望图片边界更明显，可调整素材底色，不影响本次 AC-14。
