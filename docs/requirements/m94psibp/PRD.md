# PRD — 欢迎弹窗主按钮增加右箭头图标

## 1. 文档信息

| 项 | 内容 |
| --- | --- |
| 需求编号 | `m94psibp` |
| 需求名称 | 欢迎弹窗主按钮「开始使用」左侧增加右箭头图标 |
| 版本 | v1.0（定稿） |
| 平台 | Android（Flutter） |
| 关联文档 | 同目录 `待提问清单.md`、`需求卡片.md` |
| 验收编号 | `AC-1` ~ `AC-12`，见《需求卡片.md》 |

## 2. 背景与问题

欢迎弹窗是用户首次启动 DoDroidAI 时看到的一次性模态弹窗，底部有唯一主按钮「开始使用 / Get started」，点击后关闭弹窗并停留在首页。

当前主按钮只有纯文字，缺少「继续进入」的方向性视觉提示。本次只做一处视觉增强：在主按钮文字左侧加一个右向箭头图标，不改变任何交互、数据或弹窗其他内容。

## 3. 目标

- 当欢迎弹窗展示时，主按钮内部、文字左侧出现一个与文字同色的 Material 实心右箭头 `arrow_forward`。
- 箭头在中/英、浅/深色、1x/2x 字体、320dp 窄屏下均正确显示且不破坏现有布局。
- 点击行为、关闭路径、弹窗其他内容、一次性展示逻辑与既有日志全部保持不变。

**成功标准**：AC-1 ~ AC-12 全部通过；无新增崩溃、渲染异常或布局溢出。

## 4. 用户场景

1. 首次安装或清除应用数据后启动，欢迎弹窗出现，主按钮显示「→ 开始使用」，点击按钮（文字或箭头）关闭弹窗，停留在首页。
2. 系统语言为英文时，主按钮显示「→ Get started」，点击行为同上。
3. 系统为深色模式、字体放大到 2x、屏幕宽度 320dp 时，箭头与文字仍完整可见且可点击。
4. 使用 TalkBack 时，焦点落在主按钮，只朗读「开始使用 / Get started」，不额外朗读箭头。

## 5. 范围

### 5.1 范围内

- 欢迎弹窗主按钮内部新增右向箭头图标。
- 箭头的位置、颜色、尺寸、对齐及在现有显示条件下的适配。
- 箭头对无障碍语义的影响（纯装饰）。
- 回归确认点击行为、关闭路径、弹窗其余内容与既有日志不变。

### 5.2 明确不做的事

- 不重做欢迎弹窗的结构、标题、导语、三条卖点、配图、尺寸与关闭逻辑。
- 不修改按钮文案，不新增任何文案 key。
- 不在按钮外放置箭头。
- 不引入外部图标素材、新图标库或新依赖。
- 不让读屏软件单独朗读箭头。
- 不新增埋点/日志事件，不修改 `welcome_*` 日志契约。
- 不改弹窗展示条件、一次性展示标记、首次/二次启动判定与升级迁移逻辑。
- 不新增权限、不读写业务数据、不发起网络请求。
- 不单独适配 RTL、折叠屏、分屏、悬浮窗。
- 不新增动效/动画。

## 7. 交互与视觉要求

- **位置**：箭头位于主按钮内部、文字左侧，与文字同属一个按钮点击区域（用户 Q2 已确认）。
- **素材**：Material 实心右箭头 `arrow_forward`，不引入外部素材（用户 Q3 已确认）。
- **规格（采用假设）**：图标 20×20dp，与文字间距 8dp，颜色取按钮前景色（`onPrimary`），与文字垂直居中；具体视觉值由设计说明固化（A-1、A-2）。
- **状态**：静态展示，无动效、无独立按压反馈；按压反馈沿用按钮现有态（A-4）。
- **布局**：按钮全宽、最小高度 48dp 保持不变；文字在极窄/大字号下允许换行，按钮高度可随之增加，但箭头与文字不得截断、重叠或越出按钮边界（AC-3）。
- **不做**：不改变弹窗圆角、留白、背景、按钮形状与配色体系。

## 8. 文案与本地化

| 项 | 中文 | 英文 | 是否变更 |
| --- | --- | --- | --- |
| 主按钮文案（`welcomeStart`） | 开始使用 | Get started | 否 |
| 箭头 | 图形，无文案 | 图形，无文案 | 新增图形，无文案 key |
| 按钮无障碍名称 | 开始使用 | Get started | 否（沿用按钮文案） |

- 应用当前仅支持 `zh` / `en`，箭头不涉及翻译；不新增语言资源。
- 无 RTL 语言；未来若支持 RTL，箭头是否镜像另行评估，不在本需求范围。
- 不新增权限，因此无权限申请文案、无权限说明弹窗。

## 9. 权限与隐私

- 不新增任何 Android 权限，不读取通讯录、短信、存储、位置等用户数据。
- 图标为本地 Material 字体资源，展示与点击均不联网。
- 不采集、不上报任何新数据；不引入新的第三方 SDK。

## 10. 数据契约与兼容

- **接口**：无新增/变更 API。
- **数据库**：无新增/变更表、字段或迁移。
- **持久化 flag**：一次性展示标记沿用 `welcome_flag_store`，不新增字段。
- **日志契约**：沿用 `[welcome]` 前缀与现有事件；`welcome_dismissed` 的 `method`（`button` / `back`）与 `visible_ms` 字段保持不变；不新增事件。
- **枚举**：`WelcomeDismissMethod.button` 的 wire 值仍为 `button`，不重命名、不新增取值。
- **兼容性**：老用户升级后，已看过弹窗的仍不展示；未看过的仍按现有规则展示，箭头随新版本一起出现。

## 11. 边界与异常

### 11.1 需求内边界

| 场景 | 口径 | 对应 AC |
| --- | --- | --- |
| 系统字体 2x + 320dp 窄屏 | 箭头固定 20×20 不缩放；文字允许换行，按钮高度可增加；内容不得截断、重叠或越界 | AC-3 |
| 浅色 / 深色模式 | 箭头颜色始终取按钮前景色，与文字一致，随主题切换生效 | AC-4 |
| 英文长文案 | 箭头与文字同行排列；空间不足时文字换行，箭头保持可见 | AC-3、AC-9 |
| 1 秒内连续点击 3 次 | 只关闭一次，无异常、无重复关闭 | AC-7 |
| 系统返回键关闭 | 仍记为 `method=back`，不因新增图标改变 | AC-11 |
| 点击箭头区域 | 与点击按钮等效，`method=button` | AC-5 |
| 关闭后停留页 | 停留在弹窗下方首页，不跳转、不重新弹出 | AC-6 |
| 离线 / 无网络 | 图标为本地资源，断网下展示与关闭均与改动前一致，无需新增 AC | — |
| 二次启动 | 已看过弹窗的用户不再展示，与改动前一致 | —（沿用现状，不新增 AC） |
| 弹窗展示期间进程被杀 | 沿用现有一次性标记与启动判定，不因图标引入新状态 | — |
| 点击关闭过程中再次点击 | 沿用现有 `_closing` 保护，只 pop 一次 | AC-7 |

### 11.2 系统条件逐项判断

| 项 | 判断 | 结论 |
| --- | --- | --- |
| 深色模式 | 适用：应用支持深色主题 | 箭头取按钮前景色，深/浅色均与文字同色；AC-4 |
| 系统字体缩放 | 适用：现有弹窗已按最大字号设计，本次新增图标不得破坏既有适配 | 2x 字体 + 320dp 下内容完整可见；AC-3 |
| 折叠屏 / 分屏 / 悬浮窗 | 不单独适配：目标设备未限定折叠屏；弹窗宽度随可用宽度变化，箭头为按钮内行内元素，不新增布局分支 | 320dp 窄屏 AC-3 已覆盖更严苛宽度；不单列 AC |
| 生命周期（前后台、进程被杀、首次/二次启动） | 不适用：本次不改展示判定、前后台切换与恢复逻辑；图标本身无状态 | 沿用现有行为，不新增 AC |
| 升级路径 | 不适用：无 DB、flag、接口变更；升级后是否展示由现有 `welcome_flag_store` 决定 | 与改动前一致，无需迁移 |
| 异常（网络/权限/存储/渲染） | 无网络、权限、存储依赖；图标字体随 Flutter 打包 | 点击/渲染异常由 AC-3、AC-7 覆盖；若 Material 图标字体整体缺失属应用全局资源问题，不在本需求验收范围 |

## 12. 监测指标

| 编号 | 指标 | 定义与口径 | 数据来源 | 判定 |
| --- | --- | --- | --- | --- |
| M-1 | 主按钮关闭日志完整率 | 每次点击主按钮关闭输出 1 条 `[welcome] welcome_dismissed method=button visible_ms=<非负整数>` | Debug 构建 logcat（`DebugWelcomeLog`，前缀 `[welcome]`） | 连续 10 次点击输出 10 条，完整率 100% |

## 13. 假设（采用推荐值，无需用户再确认）

| 编号 | 假设 | 来源与理由 |
| --- | --- | --- |
| A-1 | 图标 20×20dp，与文字间距 8dp，垂直居中 | 用户已确认素材但未给尺寸/间距；按推荐值，由设计说明固化 |
| A-2 | 图标颜色取按钮前景色（`onPrimary`），不新增主题色 | 与文字同色是 Q3 选项的组成部分，沿用组件默认前景色 |
| A-3 | 按钮保持全宽、最小高度 48dp；2x 字体下文字可换行、按钮可增高 | 沿用现有按钮规格，避免截断 |
| A-4 | 图标静态展示，无动效、无独立按压态 | 需求未要求动效 |
| A-5 | 不新增文案 key、埋点、权限、依赖与数据字段 | 「点击行为不变」与最小改动原则 |
| A-6 | 仅覆盖中文/英文与浅/深色；不做 RTL 镜像 | 应用现仅支持 zh/en |
| A-7 | 折叠屏/分屏/悬浮窗不单独适配 | 未限定目标设备；窄屏由 320dp 验收覆盖 |
| A-8 | 关闭方式仍只有 `button` / `back` 两种 | 沿用现有 `WelcomeDismissMethod` 契约 |

## 14. 歧义扫描

| 类型 | 发现 | 处理 |
| --- | --- | --- |
| 互相矛盾 | 未发现。「点击行为不变」与「箭头在按钮内、点击箭头也关闭」一致：图标不单独绑定手势，点击落在按钮上 | 保持；AC-5/AC-6 固化 |
| 无法判定 | 「同色」「垂直居中」「不溢出」缺可判定阈值 | 已量化：同色取按钮前景色；垂直中心偏差 ≤1dp（截图量测）；320dp + 2x 下以 uiautomator bounds 判定不越界（AC-2、AC-3） |
| 缺边界 | 2x 字体、320dp、连点、深色、返回键、离线、二次启动、进程被杀未定义 | 需求内边界已在 11.1 给出并可判定；平台/全局能力（折叠屏/分屏、RTL、图标字体整体缺失）已显式判定不单独适配或不在范围（11.2、5.2） |
| 悬空引用 | 「开始使用」对应 `welcomeStart`；「首页」为弹窗下方首页；`welcome_dismissed` 为现有日志事件；`arrow_forward` 为 Material 内置图标；「主按钮」为弹窗唯一按钮 | 均已核实存在，无悬空引用 |
