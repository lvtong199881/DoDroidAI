| 项 | 内容 |

## 2. 一句话目标

在一次性欢迎弹窗的主按钮内部、文字「开始使用 / Get started」左侧增加一个 Material 实心右箭头图标，让「继续进入」的方向更明确；按钮点击行为、弹窗其他内容与一次性展示逻辑全部保持不变。

## 3. 背景与场景

- 欢迎弹窗是用户首次启动应用时看到的主要落地界面，当前主按钮只有纯文字，没有方向性的视觉提示。
- 目标场景：首次安装或清除数据后启动 → 欢迎弹窗出现 → 用户看到带右箭头的主按钮 → 点击（文字或箭头任意位置）→ 弹窗关闭，停留在首页。
- 同一场景需覆盖中文/英文、浅色/深色、默认/2x 字体、常规/320dp 窄屏。

## 4. 范围

### 4.1 范围内

- 欢迎弹窗主按钮内部新增一个右向箭头图标（Material `arrow_forward`）。
- 箭头在中/英两种语言、浅/深色主题、1x/2x 字体、320dp 窄屏下的展示、对齐与不溢出。
- 箭头的无障碍处理：作为纯装饰，不产生独立朗读内容。
- 确认点击行为、关闭路径、弹窗其他内容与既有日志均未改变。

### 4.2 明确不做的事

- 不重做欢迎弹窗的结构、标题、导语、三条卖点、配图、尺寸与关闭逻辑（用户 Q1 已确认「只加箭头」）。
- 不修改按钮文案，不新增任何文案 key。
- 不在按钮外放置箭头（用户 Q2 已确认箭头在按钮内部）。
- 不引入外部图标素材、新图标库或新依赖（用户 Q3 已确认使用 Material `arrow_forward`）。
- 不让读屏软件单独朗读箭头（用户 Q4 已确认纯装饰）。
- 不新增埋点/日志事件，不修改 `welcome_*` 日志契约。
- 不改弹窗的展示条件、一次性展示标记、首次/二次启动判定与升级迁移逻辑。
- 不新增权限、不读写业务数据、不发起网络请求。
- 不单独适配 RTL、折叠屏、分屏、悬浮窗（理由见 PRD「系统条件」）。
- 不新增动效/动画。

| AC-2 | REQ-1 | 当欢迎弹窗展示时，箭头图标应当与按钮文字同色，且图标垂直中心与文字行中线的偏差不超过 1dp | 截图量测取色 |

| AC-6 | REQ-2 | 当点击主按钮关闭弹窗后，应当停留在首页，不跳转其他页面，也不重新弹出欢迎弹窗 | 关闭后截图/uiautomator + 等待 3 秒复查 |
| AC-7 | REQ-2 | 当在 1 秒内连续点击主按钮 3 次时，弹窗应当只关闭一次，且不出现 Flutter 异常或崩溃日志 | 连续点击 + logcat |
| AC-8 | REQ-3 | 当 TalkBack 聚焦主按钮时，朗读内容应当仅为「开始使用」（英文环境为「Get started」），不包含箭头描述 | TalkBack 聚焦朗读记录 |

| AC-10 | REQ-5 | 当在默认字体（1x）下展示弹窗时，除按钮内新增箭头外，标题、导语、三条卖点、配图（若基线存在）、按钮文案与弹窗宽高应当与改动前版本一致 | 改动前后截图 + uiautomator 结构树对比 |
| AC-11 | REQ-5 | 当按系统返回键关闭弹窗时，关闭方式应当仍为 `method=back`，行为与改动前一致 | 返回键操作 + logcat |
| AC-12 | REQ-5 | 当点击主按钮关闭弹窗时，debug 日志应当包含 `[welcome] welcome_dismissed method=button visible_ms=<非负整数>`，字段与改动前一致 | logcat 行匹配 |

## 7. 测试账号与数据

| 项 | 内容 |
| --- | --- |
| 是否需要账号 | 否。欢迎弹窗不依赖登录、账号、AI 配置或 API Key。 |
| 测试数据 | 无需预置业务数据；「首次启动」状态本身就是测试数据。 |
| 状态准备 | 安装 debug 包后执行 `adb shell pm clear com.mohanlv.dodroidai`（或卸载重装）重置一次性展示标记；点击主按钮关闭后重启应用，应不再展示弹窗。 |
| 设备要求 | Android arm64-v8a 真机或模拟器，至少一台；多设备时命令必须带 `adb -s <deviceId>`。 |
| 包名与版本 | `com.mohanlv.dodroidai`，版本 `0.1.0+1`（以开发阶段实际产出的 debug APK 为准）。 |
| 显示条件 | 中文/英文（设置 → 应用 → 语言）；浅色/深色（设置 → 应用 → 外观）；系统字体 1x 与 2x；320dp 与常规宽度各一台/一种配置。 |
| 凭据 | 不涉及任何账号密码或 API Key；禁止把凭据写入文档、代码或仓库。 |
| 来源 | 由测试阶段自建，不依赖用户提供；设备 ID 由编排层在测试阶段注入。 |
