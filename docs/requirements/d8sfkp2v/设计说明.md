- 在「开始使用」按钮下方、卡片内容区最底部新增一行居中版本号 `v0.1.0`：14sp / w400 / 行高 1.4 / `onSurfaceVariant`，距主按钮 8dp，行下 20dp，宽度撑满 footer 内容区（280dp），单行。

- **正常态**：F01（未配置 AI，基准）、F04（已配置 AI）。
- **空态**：F05（欢迎图缺失/解码失败时整块折叠；这是本页唯一有意义的「空」状态）。
- **超长文案 / 多语言**：F06（超长版本号省略）、F03（英文，版本号文本语言无关）。
- **极端数据**：F07（读取失败回退）、F08（2.0 倍字号）、F09（640×400 + 2.0 倍，内容滚动、footer 固定）。
- **深色模式**：F02（PRD 适用，出对照帧）。
- **折叠屏/分屏/悬浮窗**：PRD 明确不专项适配，**不出帧**；沿用「最大高度 80% + 内容滚动 + footer 固定」。
- **加载态**：**舍弃**。版本号要求在弹窗完全出现时已就绪（AC-9），不存在先空白后补的加载 UI；若展示后再异步补会直接违 AC-9，故不设计加载态。
- **错误态**：**保留** F07。读取失败/空串回退 `v1.0.0`，不弹错误提示、不阻塞关闭（AC-2）。
- **关闭淡出**：**不出独立静态帧**。现状是 `DialogRoute` 整体 `FadeTransition`，版本行与标题同属一个弹窗内容树，天然同透明度；静态稿无法有效评审中间帧，规则写入第 4 节，实现按 AC-11/AC-12 验收。
- **老用户升级不展示**：纯行为分支，画面与普通首页一致，不重复出帧（AC-16）。

## 6. 与现有设计规范的差异

1. **字体降级（出图环境）**：项目 Android 字体为系统默认（Roboto / 系统中文字体），Windows 出图环境无 Roboto / Noto Sans CJK，预览用 `'Segoe UI', 'Microsoft YaHei'` 近似；字形宽度和换行与真机可能有 ±1 行差异，真机以系统字体为准。未新增字体资源。
2. **新增 typography token `version`**：14 / w400 / 1.4 / `onSurfaceVariant`，只在版本行使用；字号/字重/行高来自 PRD REQ-3 与假设 A-2（与说明行一致），不是新视觉体系。
3. **新增语义色 token `closeBadgeFill`**：把现有代码的「浅色用 surface、深色用 surfaceContainerHigh」映射成主题 token（浅 `#FFFFFF` / 深 `#262B36`），不是新色值；角标描边继续用 `outline`。
4. **深色 / 640×400 无「无弹窗」真实底图**：F02、F09 背景用主题 `background` 纯色 + 遮罩示意，仅作对照帧；其余浅色帧用真实首页截图。
5. **`layouts.json` 中 image 节点 `src` 写作 `../assets/…`**：渲染器只解析 `background.src` 相对 layouts.json 的路径，image 节点按 SVG 输出目录解析；这是出图约定，不影响 SVG/PNG 产物。
6. **F09 的欢迎图条带**：为表达滚动视口，从现有欢迎图顶部裁 600×136.8dp（顶部 16dp 圆角），仅设计稿使用，不回写项目资源。
7. **不出「关闭淡出中间帧」**：现有实现是路由整体淡出，版本行不新增节点；静态稿无法比中间帧透明度，按 AC-11/AC-12 在单测/真机验收，设计侧只约束「无独立动画」。
8. **角标阴影**：真实实现有 2dp/3dp 小投影，SVG 渲染器不支持逐节点阴影，稿中用 1dp `outline` 描边表达；不改变尺寸与位置（32dp 视觉、48dp 命中盒、圆心在卡片右上角）。
