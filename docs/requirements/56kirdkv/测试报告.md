### 1.1 安装与环境说明

- 平台建议的 `adb -s <deviceId> install -r -t <apk>` 在本机 adb 37.0.3 上失败：`-t`（以及 `-d`）被 install 当成文件路径，报 `adb.exe: filename doesn't end .apk or .apex: -t`。改用 `install -r` 后成功。属工具链/命令模板问题，不是包问题；已记入“范围外发现”。

### 8.1 首页在 320dp + 2 倍字号下 OVERFLOW（范围外，P2 观感）

- 现象：`wm density 540` + `font_scale 2.0` 时，首页底部操作行（「深度思考」「智能搜索」+ 右侧图标）出现 Flutter `OVERFLOWED BY 42 PIXELS` 黄黑条。
- 归属：关闭欢迎弹窗后仍存在（`evidence/22-home-en-320dp-2x.png`），不是本需求新增说明行引起；属全应用字体缩放/窄屏既有问题。
- 口径：PRD §2.2 明确“不做全应用无障碍改造”，AC-12 只约束弹窗内按钮；本报告只记录，不判本需求失败。建议另立需求。
- 证据：`ui-screenshots/welcome/home-320dp-2x-overflow.png`、`first-show-en-320dp-2x.png`。

### 8.2 `welcome_shown` 的 `locale` 与界面语言不一致（监测口径待确认，P3）

- 现象：应用内语言切到简体中文、界面与说明行均为中文时，`welcome_shown` / `welcome_check` 仍输出 `locale=en`（系统 locale en-US）。
- 归属：既有日志字段，本需求未改日志；但 PRD §10.2 提到可按 `locale` 分组，若按该字段统计中文曝光会失真。
- 建议：产品/数据确认 `locale` 取“系统 locale”还是“应用显示语言”；若取应用语言，需另立日志需求。
- 证据：`evidence/33-welcome-log-summary.txt`（17:26:44 中文界面展示仍为 locale=en）。

### 8.3 冷启动首帧欢迎图短暂空白（范围外观察，P3）

- 现象：冷启动首次展示时，先在卡片内留下图片区域空白约 1～3s，随后欢迎图出现；标题/说明行/副标题顺序与位置不变（`13` 与 `13b` 对比）。
- 归属：既有图片解码/首帧行为，非说明行引入；仅记录，不判失败。
- 证据：`evidence/13-first-show-zh-light.png`（空白）vs `13b-first-show-zh-light.png`（图已出现）。

### 8.4 修改 `wm size`/`wm density` 后短暂空白（测试环境瞬态）

- 现象：切换 320dp/低高度后首次冷启动，Flutter 画面空白约 20s，之后自动恢复；正常分辨率冷启动无此现象。
- 归属：模拟器显示配置变更 + debug 包首帧，测试环境瞬态；不是本需求缺陷。
- 处理：测试结束已恢复 `wm size`/`wm density`/`font_scale`/`uimode`。

### 8.5 平台安装命令与实际 adb 不匹配（环境建议）

- 平台模板：`adb -s <deviceId> install -r -t {artifact}`；本机 adb 37.0.3 把 `-t`/`-d` 当文件名。
- 实际：`adb -s emulator-5554 install -r <apk>` 成功。
- 建议：修正模板或固定 adb 版本；不阻塞本需求。
