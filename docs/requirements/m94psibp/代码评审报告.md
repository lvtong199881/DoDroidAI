## 3. 问题清单

### R-1（建议）图标颜色与按钮前景色是两个来源

- **位置**：`flutter_app/lib/widgets/welcome_dialog.dart:245-252`
- **证据**：`Icon(..., color: scheme.onPrimary)` 显式取色，而该 Icon 直接位于 `FilledButton` 子树内。Flutter 的 `ButtonStyleButton` 会把 `resolvedIconColor`（`iconColor` → `foregroundColor` → 默认 `onPrimary`）合并进子树的 `IconTheme`（SDK `button_style_button.dart:395-402、550-554`）；`Material 3` 下 `FilledButton` 默认前景即 `colorScheme.onPrimary`，本仓库 `app_theme.dart` 也未覆写 `filledButtonTheme`，因此当前两条取色恰好相等，新增测试 `expect(startTextColor(...), icon.color)` 能通过。
- **风险**：颜色有两个来源。后续若给 `filledButtonTheme` 设置 `foregroundColor`，或该按钮出现 disabled 态（默认 disabled 前景是 `onSurface` 派生色），图标不会跟随文字变色；现有测试锁定的是「当前相等」，锁不住「跟随按钮」。
- **方向（建议级，不阻断）**：可去掉 `color` 参数，让图标继承按钮注入的 `IconTheme`；若按技术方案 §5 有意固定取色，建议在该行补一句注释说明「有意不继承按钮前景」，避免后人误判为冗余而反复修改。本项不影响本次 AC。

### R-2（建议）图标几何断言在 helper 与单用例中重复

- **位置**：`flutter_app/test/welcome_dialog_test.dart:900-927`（`expectStartContentInsideButton`）、`929-966`（AC-1/AC-2 用例）、`978-1001`（AC-9 用例）
- **证据**：AC-1 与 AC-9 各自重复了 helper 中的 4 条几何断言（图标 20×20、图标在文字左侧、间距 8±0.5、垂直居中 ±1），AC-1 另加了颜色、整组居中、按钮高 48。
- **风险**：后续若调整间距/尺寸/居中口径，需要同时改 helper 与两处用例，容易漏改导致断言漂移。重复本身不产生错误，故列为建议。
- **方向（建议级）**：AC-1/AC-9 先调用 `expectStartContentInsideButton`，再只保留各自增量断言（颜色、整组居中、英文文案），减少维护点。

> 备注：`ExcludeSemantics` 包住无 `semanticLabel` 的 `Icon` 略冗余（`Icon` 无 label 时本身已不朗读），但作为 AC-8 的显式防线无副作用，不单列问题。
