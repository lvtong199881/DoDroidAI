## 范围外发现

1. **在线改变窗口尺寸时出现瞬态 overflow（非首启路径）**：弹窗已打开时执行 `wm size 640x400` + `wm density 160`（1080×2220/440dpi → 640×400/160dpi），约 4s 后仍出现 `BOTTOM OVERFLOWED BY 147 PIXELS`，版本行暂时不可见；轻扫后恢复。清数据后直接以 640×400/2x 首启、以及滚动后均正常（无 overflow）。正常用户不会触发该路径，PRD 也明确折叠屏/分屏/悬浮窗不做专项适配，故只记录，不判失败。现场：`version-small-640x400-2x-live-resize-overflow.png`。
2. **无障碍节点聚焦矩形待确认**：uiautomator 中 `content-desc="v0.1.0"` 的节点 bounds 为 `[0,66][1080,2154]`（整个弹窗内容区），而不是版本行文字矩形；开启 TalkBack 后单击版本行，绿色焦点框覆盖整个应用内容区，无法确认“聚焦矩形是否只包住版本行”。文字本身正确、`clickable=false`、非 `Button`，AC-13 的文字与非按钮要求通过；焦点矩形属平台语义表现，PRD 未规定，列入待确认交人拍板。现场：`version-talkback-focus-version.png`。
3. **AI 配置页语言未跟随应用语言**：应用/欢迎弹窗为英文时，从「Set up AI」进入的「新建配置」页仍显示中文（新建配置、基本信息、API 配置、自定义等）。与本需求无关，只记录。
4. **模拟器 screencap 刷新滞后（环境）**：弹窗出现/消失后数秒内 `screencap` 可能返回旧帧或空白（320×640 首屏曾截到空白/主页；横屏旋转时截图出现黑白分区），因此相关视觉用例改以重复截图 + uiautomator 语义树交叉验证，或记为未覆盖。属测试环境表现，不影响应用行为结论。
