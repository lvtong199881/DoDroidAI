## 5. 偏差、未验证项与残余风险

### 5.1 AC-8 欢迎图缺失/加载失败：未验证

- **为什么没测：** 欢迎图是打进 APK 的 Flutter asset。debug 包的 `app_flutter/flutter_assets` 只解出 kernel/snapshot，图片仍从 APK 内读取；不改包、不重签名就无法在真机上让 asset 缺失或解码失败。本轮未改包（验收必须测交付件本身），也未读测试报告，因此不引用测试阶段的 widget 注入结论。
- **已确认部分：** 设计说明 F06 给出 56dp 顶部预留、关闭按钮位置不变、标题净距 60dp 的方案；PRD 把该状态列为 AC-8。
- **影响：** 无图时是否真的折叠图片区、56dp 预留是否足够、按钮是否压标题，本轮没有一手证据。
- **建议：** 由测试阶段的 `heroAssetOverride` / 缺失资源 Widget 用例兜底，或补一次受控的注入测试；不阻塞本轮通过。
