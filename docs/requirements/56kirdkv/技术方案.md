## 0. 结论

在 `flutter_app/lib/widgets/welcome_dialog.dart` 的标题文案区，按「主标题 → 说明行 → 副标题」插入一个普通 `Text`，文案取 `AppStrings` 新增 key `welcomeAiHint`，样式 13sp / w400 / 行高 1.4 / `onSurfaceVariant` / 居中，间距 6dp 与 12dp；不改构造函数、不改门控、不改日志、不加动画、不加手势、不加路由。测试以 Widget 测试补 21 条 AC，另在 app 级回归门控与四个关闭出口，真机做一次冷启动冒烟。

改动面：2 个源码文件 + 4 个测试文件；无数据迁移、无配置变更、无权限、无资源、无依赖变更。

### 2.2 目标结构（标题文案区）

```
Padding(24, showHero ? 20 : 20+56, 24, 8)
└─ Column(stretch)
   ├─ Text(welcomeTitle)                          // 既有，不动
   ├─ SizedBox(height: welcomeHintTitleGap = 6)   // 新增
   ├─ Text(welcomeAiHint, key: welcomeDialogAiHintKey)  // 新增
   ├─ SizedBox(height: welcomeHintSubtitleGap = 12)     // 新增
   └─ Text(welcomeIntro)                          // 既有，文案/样式/位置关系不变（整体下移）
```

原来的 `SizedBox(height: 8)` 被上面三行替换；副标题字号、颜色、文案、对齐均不动，只整体下移约 28.2dp（18.2 + 6 + 12 − 8）。说明行落在既有的 `SingleChildScrollView` 内，滚动、滚动条、footer 固定逻辑全部复用。

### 2.3 关闭淡出为什么不用改代码

`showDialog` → `DialogRoute` 用 `transitionDuration: 150ms` 的 `FadeTransition(opacity: animation)` 包住整棵 dialog（Flutter 3.50 `material/dialog.dart` L1852、L1878）。说明行是这棵树里的普通子节点，天然与主标题共享同一透明度；只要不插入 `AnimatedOpacity`/`Opacity`/第二段 `FadeTransition`，REQ-4 即成立。方案因此把「不加动画」写成硬约束，并由测试守住（见 §8 AC-14/15）。

## 4. 接口定稿

本需求无网络、无存储、无跨端协议；「接口」= 文案 key 契约 + Widget 对外符号契约 + 布局/异常语义。以下全部定稿，不留待定。

### 4.1 文案契约（`flutter_app/lib/l10n/app_strings.dart`）

| key | zh | en | 类型 | 空值语义 |
| --- | --- | --- | --- | --- |
| `welcomeAiHint` | `随时可以在设置里改 AI 配置` | `You can change your AI config anytime in Settings.` | `String`（非空、无插值） | 不允许空/null；两套 map 必须同时存在 |

- 取值规则沿用 `t(String key)`：`locale.languageCode == 'en'` → en；其余（含 `fr`、`zh-Hant`）→ zh；两套都缺 → 返回 key 字面量 `welcomeAiHint`。**缺 key 视为缺陷**，由测试 `每个欢迎 key 在中英两边都有值` 与逐字断言守住。
- 不新增 `getter`：现有 `welcomeTitle`/`welcomeIntro` 均以 `strings.t('...')` 使用，说明行同源，避免多一套 API。
- 中文逐字：`随时可以在设置里改 AI 配置`（`AI` 前后各一个半角空格，无句号，首尾无空格）。
- 英文逐字：`You can change your AI config anytime in Settings.`（含句末句号）。
- 不做 `trim()`、大小写转换、复数或占位符替换。
